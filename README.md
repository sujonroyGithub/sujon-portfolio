# Sujon Roy - Portfolio Website

A responsive personal portfolio built with Django, featuring dark/light mode, animated sections, a project showcase, a journey timeline and a working contact form.

Live site: https://sujonroy.pythonanywhere.com

## Features

- Dark / light mode toggle
- Typing animation, animated counters and skill bars
- 3D tilt project cards
- Experience and education timeline
- Contact form (messages saved in the admin panel)
- All content managed from the Django admin panel

## Built With

- Python, Django
- HTML, CSS, JavaScript, Bootstrap 5
- SQLite
- Deployed on PythonAnywhere
